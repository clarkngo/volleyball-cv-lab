# Notebooks

One notebook per experiment, named `YYYY-MM-DD-short-topic.ipynb` (e.g. `2026-11-27-yolo-ball-detection.ipynb`).

At the top of each notebook, record:
- the question it answers,
- the clips used (`clip_id`s from `../clips/manifest.csv`),
- the model and version,
- the result in one line.
